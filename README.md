## ✨ 特色能力速览

### 📁 文件夹批处理
- 快速加载整个文件夹图片、自动索引、自动统计
- 配合 **批处理进度条 🐋** 直观显示当前处理进度
- 自动新建输出目录，跨平台路径斜杠自动修正

### 💾 智能保存
- 支持 **JPG 指定 DPI**（打印/证件照常用 300dpi）
- 高级保存支持自定义压缩、元数据、命名规则

### 🎨 自动排版
- **单尺寸 / 多尺寸混合 / 批量自动** 三种排版模式
- 适配 A4/A5/6 寸等纸型，自动拼版到打印规格
- 身份证自动扶正并排版到标准身份证模板

### 👤 人脸 & 证件照生产流
- 人脸检测 → 面部对齐 → 证件照裁剪 → 服装/发型替换 → 自动排版一条龙
- 内置女士西装/马甲/衬衫/减龄上衣、结婚登记照等 **几十套服装模板**（见 `image/ID_Photo/` 目录）
- 人脸自动矫正 + 肤色差值 + 头顶遮罩扩展，保证换装/换发型自然

### 🎭 遮罩全家桶
- 检测 → 分析 → 生长 → 模糊 → 对齐 → 裁剪 → 恢复 → 混合运算，覆盖绝大部分遮罩场景
- 主体保护裁剪、保留遮罩区域抠背景、图像差异生成遮罩等进阶能力

### 🌈 颜色 & 取色
- 取色器、常用色板、颜色空间转换、主色提取，配色/色偏校正场景常用

## ⚙️ 安装

### 方法一：Git 克隆（推荐，便于后续更新）

```bash
cd ComfyUI/custom_nodes/
git clone https://github.com/goohai/Goohaitools-comfyui.git
cd Goohaitools-comfyui
pip install -r requirements.txt
重启 ComfyUI 即可。

方法二：手动下载
下载 Goohaitools-comfyui ZIP 包
解压到 ComfyUI/custom_nodes/ 目录，确保目录名为 Goohaitools-comfyui
进入该目录执行 pip install -r requirements.txt
重启 ComfyUI
依赖说明
requirements.txt 主要依赖：

opencv-python / scipy / scikit-image / matplotlib：图像处理核心
mediapipe>=0.10.20：人脸/关键点检测
dlib-bin>=19.24.6：人脸 5 点关键点模型（仓库已内置 shape_predictor_5_face_landmarks.dat）
若使用国内网络 pip 安装慢，requirements 已默认配置清华镜像源（-i https://pypi.tuna.tsinghua.edu.cn/simple）。

🔧 前端扩展组件
本插件在 web/js/ 下提供多个前端 Widget 增强：

BOOLEAN.js 布尔开关组件
GoohaiNote.js 节点备注/便签
colorWidget.js 颜色取色器 Widget
goohai_universal_slider.js 万能滑条前端交互
id_photo_clothing.js / marry.js 证件照、结婚登记照服装选择前端组件
启用后部分节点（取色器、万能滑条、服装切换等）会有更友好的交互 UI。
